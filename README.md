# Paket Workflow n8n untuk UMKM — Kontenlaris Studio

Empat workflow n8n siap impor untuk mengotomatiskan admin toko Anda:

| # | Workflow | Fungsi |
|---|---|---|
| 1 | Catat Order Otomatis | Order masuk → tercatat ke Google Sheets → notifikasi Telegram ke pemilik |
| 2 | Pengingat Pembayaran | Order belum lunas yang jatuh tempo diingatkan sopan & otomatis tiap pagi |
| 3 | Rekap Penjualan Harian | Rekap omzet & produk terlaris dikirim ke pemilik tiap malam 21:00 |
| 4 | Balas Lead Otomatis | Lead baru tercatat, menerima email sambutan, pemilik langsung tahu |

Semua memakai node bawaan n8n (Webhook, Google Sheets, Telegram, Gmail, Schedule, Code) — tanpa node tambahan, tanpa biaya per pesan dari kami. Kredensial Anda sambungkan sendiri di n8n Anda; tidak ada data yang melewati server kami.
